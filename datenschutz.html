2. Grundsatz

Diese Website ist eine rein statische Seite. Es gibt keine Benutzerkonten, keine Formulare, keine Kommentarfunktion, keine Newsletter und keine Zahlungsvorgänge. 4. Lokale Speicherung im Browser

Die Seite speichert einige Einstellungen im lokalen Speicher (localStorage) deines Browsers, damit sie beim nächsten Besuch erhalten bleiben:

  • gewählte Sprache und gewähltes Design
  • gewählte Kartenansicht und Sortierung der Länderliste
  • Lernfortschritt (welche Länder bereits angezeigt wurden)
  • Punktestand des Quiz

Diese Angaben verbleiben ausschließlich auf deinem Gerät, werden nicht an den Server oder an Dritte übertragen und enthalten keine personenbezogenen Daten. Sie dienen allein den von dir ausdrücklich gewünschten Funktionen (§ 25 Abs. 2 Nr. 2 TDDDG). Du kannst sie jederzeit über die Einstellungen deines Browsers löschen; die Seite funktioniert danach unverändert weiter.

When you visit, the host automatically processes technical access data sent by your browser: IP address, date and time of the request, the file requested, amount of data transferred, HTTP status code, referrer, and browser and operating system details. The site stores a few preferences in your browser's localStorage so they survive until your next visit: chosen language and theme, map view and list sorting, learning progress (which countries you have seen) and your quiz score. This data stays on your device, is never transmitted to the server or to third parties, and contains no personal data. It serves only the functionality you explicitly requested (§ 25 (2) no. 2 TDDDG). You can delete it at any time via your browser settings; the site continues to work normally afterwards.
